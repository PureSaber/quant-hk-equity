# 首版实施与验收

范围：港股直投、HKD、现金账户、日频只做多；实现真实日线到费用后时间切分研究报告。数据层与执行层采用独立分支，避免改动其他任务工作区。

软件验收条件：

1. 港股证券身份、金额单位和交易日历独立于A股。
2. 实际抓取快照可校验，失败不能被当作成功。
3. 因子复用quant-factors，所有交易信号比成交至少早一个交易日。
4. 整手、双边税费、逐项舍入、现金交收约束生效；共享账本每笔分币种平衡。
5. 所有预定候选保留训练结果，选定后再运行留出期，基准使用相同约束。
6. 结果含配方、代码版本、快照哈希、逐笔费用、信号、订单、净值和HTML报告。
7. 独立清洁环境可安装，测试与真实数据命令可复现。

研究认证仍要求：历史PIT证券主表与规则变更；完整分红/供股/拆并股事件及支付日期；官方交收日历；停牌和退市终值；前瞻冻结的候选。首版不会将这些未完成项标记通过。

后续研究优先级：补齐公司行动与历史主表→红利/质量/价值→南向资金与AH相对价值。后两类策略不能用当前不含财务和南向持仓的数据替代实现。
