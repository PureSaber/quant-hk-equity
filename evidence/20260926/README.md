这是探索性软件闭环验收。`investable=false`；未复权价格收益不包含分红和其他公司行动，不能据此认定策略有效或可投资。

## 数据与结果

- 数据：新浪港股日线，5只证券，2025-07-01至2026-09-25，307个交易日，共1535行。
- 训练：2025-08-01至2025-12-31，104个交易日；在预定的动量、低波动两个候选中按训练Sharpe选中20日低波动。
- 留出：2026-01-02至2026-09-25，181个交易日；与训练期独立从100万HKD现金起步。

|留出期情景|价格净收益|最大回撤|费用及滑点/HKD|
|---|---:|---:|---:|
|20日低波动|12.05%|-7.68%|8,542.51|
|同池等权基准|-1.76%|-15.90%|3,398.62|
|选定策略双倍成本情景|11.42%|-7.79%|17,633.62|

该结果来自当前固定观察名单与当前整手数的历史情景，存在选择和幸存者偏差；没有历史PIT主表、完整公司行动和认证交收日历。时间切分是回顾性探索，不是前瞻预注册。双倍成本改变现金约束下的成交数量，因此实际总成本不必恰好翻倍。

## 文件与复现

`study.json`记录配置、代码、实际安装的共享仓库提交和锁文件哈希；`selection.json`是在评价留出期前保存的训练选择；`summary.json`是完整汇总；`snapshot-manifest.json`包含本地原始行情文件哈希；`output-checksums.json`对应本地完整输出目录，`verification.json`记录实际核验结果。

行情原始文件和完整逐日输出未在本目录再分发。在保存原始快照的本地工作区，用README命令指定该快照并选择新的输出目录，即可重跑；新下载的数据可能因供应商修订而具有不同哈希，不能冒充本次同一快照。
